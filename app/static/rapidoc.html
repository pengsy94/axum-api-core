快速开始 OpenAPI JSON Swagger UI

先看这 4 件事

这个项目默认把 HTTP 当成“通信是否连通”的语义层， 业务是否成功请优先看响应体里的 code 字段。

Base URL 当前域名
鉴权方式 Bearer Token
结果判断 优先看 body.code
业务成功：code=200 登录失败：HTTP 200 + code=401 就绪失败：/ready 可能返回 503

常用入口

OpenAPI 原始规范 /api/openapi.json
可交互调试页 /swagger
运行状态 /health  ·  /ready

鉴权说明

  • 先调用 POST /api/login 获取 token
  • 请求头使用 Authorization: Bearer <token>
  • 当前仓库中，认证中间件已提供，但并未默认挂到全部路由

快速开始

最常见的接入路径就是：登录拿 token，然后访问业务接口。

POST
/api/login 演示登录，默认账号为 admin@example.com / admin123
GET
/api/users?page=1&page_size=20 用户列表接口，适合作为联调验证入口

响应结构

{ "code": 200, "data": {}, "message": "success", "errors": null }

结果语义

场景 如何判断
业务成功 code = 200
业务失败 code = 400/401/403/404/409/500
参数校验失败 看 errors 字段
服务是否能接请求 看 HTTP 状态 / /health / /ready
